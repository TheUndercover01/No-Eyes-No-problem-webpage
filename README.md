# No Eyes, No Problem

Project page for *No Eyes, No Problem: What Does Touch Contribute to Blind Baoding Ball Manipulation?*
(Ayush Deshmukh\*, Nalin Agarwal\*, Elle Miller, Sethu Vijayakumar — University of Edinburgh).

Live at https://noeyesnoproblem.github.io/

Plain HTML/CSS/JS, no build step. Run locally with `python3 -m http.server 8000`.
